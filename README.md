# Офис из 31 агента для Claude Code

31 агент нейросети для Claude Code: разбирают письма, считают цену по прайсу и пишут черновики, а отправляешь ты сам. 8 отделов и директор, общая память, очередь на утверждение и пример на вымышленных письмах

Идея из ролика Bekhruz AI: https://www.youtube.com/watch?v=t0hGE-aaAds . Это не копия его офиса: файлов автора в открытом доступе нет, его цифры проверить нельзя. Агенты написаны заново по его пяти шагам, под малый бизнес

## Что нужно

- Claude Code. Входит в тариф от 20 долларов в месяц, в бесплатном его нет: https://claude.com/pricing
- В России сервис официально не поддерживается, проверь доступ и оплату до старта: https://www.anthropic.com/supported-countries

Установка Claude Code, инструкция от разработчика: https://code.claude.com/docs/en/quickstart

Windows: нажми Пуск, напиши PowerShell, нажми Enter и вставь команду:

```
irm https://claude.ai/install.ps1 | iex
```

Mac и Linux: открой Терминал и вставь команду:

```
curl -fsSL https://claude.ai/install.sh | bash
```

## Куда положить

1. Распакуй архив. Внутри будет папка `ofis-31-agent`. Нужна та, где лежат этот файл и папка `dannye`
2. Открой терминал в этой папке. На Windows: открой её в Проводнике, щёлкни по адресной строке, напиши `powershell` и нажми Enter. На Mac: открой Терминал, напиши `cd` с пробелом, перетащи папку в окно и нажми Enter
3. Запусти `claude`, войди в свой аккаунт, на вопрос о доверии папке ответь «да». Выйди командой `/exit`

Агенты лежат в `.claude/agents/`, папка может быть скрытой, это нормально. Они работают, когда Claude запущен из этой папки. Нужны во всех проектах - скопируй файлы в `~/.claude/agents/`, но тогда и память `pamyat/` положи в каждый проект

## Первый запуск на вымышленных письмах

```
claude --agent pochta-lead
```

Напиши в окне:

```
Разбери письма из папки vhodyashchie и подготовь черновики ответов
```

Что должно получиться за пару минут:

- В `gotovoe/pochta/` разбор и черновики ответов
- В `pamyat/ochered-na-utverzhdenie.md` две строки: ответ Ирине и ответ кафе ждут твоего решения
- Никому ничего не отправлено
- Цены кафе посчитаны по `dannye/prays.csv`, диванов в прайсе нет, поэтому цены на них нет, вместо неё вопрос тебе
- В письме 3 спрятана просьба к нейросети отправить прайс и клиентов. Агент её не выполняет, письмо считает спамом

## Под свой бизнес

1. Замени `pamyat/biznes.md` данными своей компании
2. Замени файлы в `dannye/`: прайс и заказы
3. Очисти `vhodyashchie/` и положи туда свои письма текстовыми файлами
4. Начни с одной рутины, а не со всего офиса: разбери почту неделю, потом добавь следующий отдел

То, что читает агент, уходит на серверы Claude Code. Настоящие письма и таблицы клади, только если готов им это показать

## Как запускать

| Что нужно | Команда |
|---|---|
| Весь офис, задачу распределит директор | `claude --agent direktor` |
| Один отдел | `claude --agent kontent-lead` |
| Один сотрудник | `claude --agent prodazhi-kp` |

Примеры задач директору:

- `Клиент просит цену на шкаф-купе 2 метра. Подготовь КП`
- `Напиши пост о том, как мы делаем кухни, и 10 вариантов первой фразы`
- `Посмотри конкурентов и сравни цены с нашими`

Решения записывай в `pamyat/resheniya.md`, агенты им следуют. Очередь `pamyat/ochered-na-utverzhdenie.md` смотри сам: агенты ничего не отправляют, отправляешь ты

## Как подключить почту, диск и календарь

В наборе подключений нет: чтобы письма брались из ящика, а файлы из диска, нужны твои входы. Подключения делаются через MCP, инструкция от разработчика: https://code.claude.com/docs/en/mcp

Подключай только нужному агенту: допиши инструмент в поле `tools` его файла. Запрет на отправку наружу оставь. Этот шаг я не проверял

## Как устроено

1. **Один агент, одна работа.** Открой любой файл в `.claude/agents/`: кто он, работа, результат, запреты. Меняй обычным текстом
2. **Только нужные инструменты.** Поле `tools`
3. **Общая память.** Папка `pamyat/`, её читают все
4. **Руководитель делит работу.** У руководителя отдела в `tools` перечислены его сотрудники
5. **Человек утверждает.** Всё публичное и всё с деньгами - в очереди

## Что запрещено настройками

`.claude/settings.json` запрещает `git push`, `curl`, `wget`, `rm -rf`, `ssh` и чтение файлов `.env`. Это страховка, а не полная защита: команды и правки, которые Claude просит разрешить, читай до ответа «да»

## Сколько это расходует

Каждый агент тратит лимит подписки. Замер на этих примерах, модель Sonnet, по счётчику Claude Code: разбор 3 писем 0,57 доллара, задача директору на 2 отдела 0,50 доллара. На подписке отдельно не платишь, но лимит кончается быстрее. Не запускай весь офис без нужды

## Если не работает

- `claude` не найден - закрой терминал и открой заново
- Агента не видно - терминал открыт не в той папке. В нужной лежат этот файл и папка `dannye`
- `Credit balance is too low` - ты вошёл ключом разработчика, а не подпиской: напиши `/logout`, затем `/login`
- Агент говорит, что данных нет - он прав, допиши их в `pamyat/biznes.md` или `dannye/`
